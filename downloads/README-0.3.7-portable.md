# Windows 0.3.7-portable · 원본과 확정 매핑을 프로그램 폴더에 보관

[EXE 포함 ZIP 다운로드](Bbolprom-Windows-x64-v0.3.7-portable.zip)

이전 앱에서 **앱 종료** 후 ZIP 전체를 쓰기 가능한 새 폴더에 풀어 **Bbolprom.exe**를 실행하세요. EXE/app/runtime을 함께 유지하며 Python은 별도로 설치하지 않습니다.

1. **이전 버전을 사용했다면** 카드·이미지·사용자 태그 수정 이력·호출 원장을 프로그램 옆 `data`로 복사하고 검증합니다. 자료 준비 화면이 끝날 때까지 기다려주세요. 원래 자료 폴더는 그대로 남깁니다.
2. 이미 등록된309개는 바로 유지됩니다. 상단 **PT.hwpx 원본 보관**으로 PT를 한 번 선택하면 문서 전체를 `data/sources/PT.hwpx`에 보관합니다. 다시 분류하거나 태그·하이라이팅·이미지 연결을 만들지 않습니다.
3. **처음 사용하는 PC라면** PT.hwpx 등록 → 검토 → 이미지 연결 등록을 진행합니다. 확정309개 ID와531개 이미지 참조/522개 경로를 그대로 적용하며 원본 전체도 보관합니다.
4. 신규 카드의 원문·이전 원문과 원본이미지는 `data/new_cards/카드ID`에 따로 보관합니다. 카드의 **신규 카드 원본 폴더**, 좌측 **자료 폴더 열기**로 확인합니다. 변경은 앱에서 진행하며 외부 파일 수정은 DB에 자동 반영하지 않습니다.
5. 다른 PC로 옮길 때 앱 종료 후 **프로그램 폴더 전체(data 포함)**를 복사하세요. 경로가 바뀌어도 매핑과 수정 이력을 유지합니다. API키는 새 PC에서 다시 등록합니다.

업데이트는 `data`를 유지하고 프로그램 파일만 교체합니다. 새 빈 폴더에서 실행하면 현재PC의 마지막 자료 위치를 참고해 복사하며, 복사 도중 실패하거나 기존 앱이 실행 중이면 전환하지 않습니다. 알려진 이전 data가 사라졌다면 오래된 LocalAppData로 조용히 되돌아가지 않고 data를 가져오도록 안내합니다.

전체 **백업 저장**에는 PT·DB·원본이미지를 포함합니다. 작은 수정 전 자동 백업은 큰 PT를 반복 포함하지 않습니다. 전체 백업 가져오기 UI는 아직 없으며 현재 권장 이사 방법은 폴더 전체 복사입니다. 베이스 PT와 검증 이미지 합계 약1.56GB에 신규 자료/백업 용량이 추가됩니다.

최초309개 정답은 영구 보존하며 사용자가 직접 바꾼 태그만 별도 이력에 적용합니다. API가 원본을 덮어쓰지 않습니다. 다른 API 엔진 개선 전체를 구현한 버전은 아닙니다.

통합179개(휴대형23개와 실제 자식프로세스2개 포함), 새 휴대형 브라우저8개, 수동태그 브라우저9개, 기존 브라우저16개 통과. 패키지1350개 파일 해시·ZIP CRC·Linux에서 패키지 소스의 경로 이동 시험을 확인했습니다. **새 버전의 실제 Windows 실행·605MB 원본PT·실제API는 아직 미검증**입니다. 합성자료·임시DB를 사용했고 사용자DB·실제키·유료API 호출은 사용하지 않았습니다.
