# 0.3.9 · 태그 적용↔전체 보기 한 버튼 전환

[0.3.8용 작은 업데이트 ZIP](Bbolprom-UI-Patch-v0.3.8-to-v0.3.9.zip) · [전체 Windows ZIP](Bbolprom-Windows-x64-v0.3.9-filtertoggle.zip)

기존0.3.8 사용자는 약169KB의 작은 업데이트를 사용할 수 있습니다.

1. 현재 뽈프롬 화면 안의 **앱 종료**를 누릅니다.
2. 작은 ZIP을 열어 안의 **app 폴더와 모든 파일**을 복사해 **현재 Bbolprom.exe가 있는 폴더**에 붙여넣고 같은 이름은 바꿉니다.
3. 기존 Bbolprom.exe를 실행합니다. 상단0.3.9-filtertoggle 표시를 확인합니다. data는 패치에 없으며 PT를 재등록할 필요가 없습니다.

태그를 고르고 **태그 적용**을 누르면 AND 결과와 함께 같은 버튼이 **전체 카드 보기**로 바뀝니다. 누르면 선택을 유지한 채 전체 보기로 돌아가고 **태그 적용**으로 바뀝니다. **태그 초기화**만 선택/적용을 모두 해제합니다.

기존309개 정답/원문/태그/근거/이미지 매핑과 사용자 태그 수정 이력·API·원본보관·저장 구조는 유지합니다. 새로 선택한 태그는 다시 적용할 때 결과에 반영합니다. 작은 ZIP은0.3.8용이며 전체 설치본이 아닙니다. 다른 버전이라면 전체ZIP을 사용하고 기존 data를 보존하세요.

Chromium 회귀16개 통과. 선택 유지/AND/버튼 위치·폭/새로고침 후 상태/Enter 재적용/초기화와 기존 등록·하이라이팅·수정·다운로드를 확인했습니다.0.3.8 번들에 패치를 덮어쓴 결과가 전체0.3.9의1350개 파일 해시와 일치하고 임시 사용자 data 사본이 그대로인 것을 확인했습니다. 해당 패키지 소스의 원본 복원/폴더 이동 smoke는 Linux에서 통과했습니다. 실제 Windows0.3.9/실제PT/실API는 이번에 미검증입니다. 백엔드가 동일해 Python188개 통합은 이번에 다시 실행하지 않았으며188개는 이전0.3.8의 결과입니다.
