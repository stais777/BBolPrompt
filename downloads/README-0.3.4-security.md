# Windows 0.3.4-security · API 보안 준비 시험판

[EXE 포함 ZIP 다운로드](Bbolprom-Windows-x64-v0.3.4-security.zip)

이전 앱을 종료하고 ZIP 전체를 새 폴더에 풀어 **Bbolprom.exe**를 실행하세요. EXE와 app/runtime 폴더를 함께 유지합니다. Python 별도 설치는 필요 없습니다. 기존 데이터 폴더는 그대로 사용합니다.

이번 변경은 API 보안 준비입니다. **309개 베이스·이미지 매핑·태그/하이라이팅 판단은 변경하지 않았습니다.** 실제 베이스파일 시험과 사용자 확정 전 후속 엔진 개선은 계속 보류합니다. API는 기본 꺼짐이며 베이스파일 등록 시험에는 키가 필요 없습니다.

- 키는 전용 비밀번호 입력칸에서 등록·교체·삭제하며 Windows 자격 증명 관리자에만 보관합니다. 환경변수/평문 파일 대체 경로는 없습니다. 일반 설정·DB·백업·진단 ZIP에 키를 넣지 않습니다.
- 공식 OpenAI 주소만 허용합니다. 선택 모델은 gpt-6.1-sol이며 실제 계정 접근·호환성은 미검증입니다.
- 일일 호출·예상 비용 한도(UTC)와 모델 입출력 단가를 설정해야 유료 호출이 가능합니다. 호출 전 영구 기록하고 재실행·설정 변경으로 초기화하지 않습니다. 실패분의 비용 예약은 유지하며 자동 재시도하지 않습니다.
- 로컬 보관값 삭제와 공급자에서 키 폐기는 다릅니다. 보관함과 로컬 추정 한도는 계정 탈취·악성코드·공급자 청구까지 보장하지 않습니다.

통합136개, 그 안의 보안 표적16개, 보안 브라우저6개, 기존 화면 회귀16개를 통과했습니다. 가짜 키·모의 Win32/모의 API 시험입니다. Windows 교차 빌드·1346파일 해시·ZIP CRC·Linux 호스트의 패키지 소스 시험을 수행했습니다. **실제 Windows 보관함/EXE 실행, 실제 API와 실제 베이스파일은 미검증**입니다.
