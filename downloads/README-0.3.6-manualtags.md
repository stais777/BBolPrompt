# Windows 0.3.6-manualtags · 최초309 보존 + 사용자 태그 수정

[EXE 포함 ZIP 다운로드](Bbolprom-Windows-x64-v0.3.6-manualtags.zip)

이전 앱에서 **앱 종료** 후 ZIP 전체를 새 폴더에 풀어 Bbolprom.exe를 실행하세요. EXE/app/runtime을 함께 유지합니다. 기존 데이터 폴더와 연결된 베이스파일 이미지를 그대로 사용하며 Python 별도 설치는 필요 없습니다.

1. 기준 카드 선택 → **태그 수정** → 태그명·소속·근거를 수정하거나 태그 추가/삭제 → **저장**.
2. **태그 수정 이력 · 복원**에서 이전 수정본 또는 **최초 정답 원본으로 복원**.
3. 확인 뒤 **진단 로그 내보내기**로 저장한 Bbolprom-Local-*.diagnostic.zip을 전달하면 원본 보존과 수정 이력의 개수/해시를 확인할 수 있습니다. 원문·이미지·사용자 태그명·API키는 진단에 넣지 않습니다.

최초 정답309개 원본은 유지하고 수동 수정본만 별도 이력에 적용합니다. 태그명만 바꾸면 다중 하이라이팅 구간을 보존합니다. 원문·이미지 편집과 기준 카드 API분석은 차단합니다. 운영 분류의 비활성화·표시명 변경은 기준 태그를 자동 변경하지 않습니다. 다른 창에서 먼저 저장했으면 오래된 편집 내용을 거절합니다.

관련 기준 카드 사례 제공 옵션을 켜면 최신 사용자 확정 태그·원문 발췌·근거를 신규 카드 API의 제한된 참고자료에 제공합니다. 모의 호출로 연결·기존 자료 우선순위를 검증했으며 실제 API품질 시험은 아닙니다. 이 기능은 모델 재학습이나 다른 카드의 자동 수정이 아닙니다. 한영 검색 등 나머지 엔진 개선은 별도 범위입니다.

통합154개(새 수동편집14개 포함), 수동편집 화면9개, 기존 화면16개 통과. 백업을 별도 저장소에 복원해 최초309/수정 이력/531이미지 참조·522경로와 신규 카드 원본 파일의 해시를 확인했습니다. Windows 교차 빌드·1348파일 해시·ZIP CRC·Linux 호스트의 패키지 소스/수정·원본복원 시험을 통과했습니다. **새 기능의 실제 Windows 실행·실제 API는 아직 미검증**이며 사용자DB·실제 키·유료호출은 사용하지 않았습니다.

수동 수정 뒤에는0.3.6 이상을 사용하세요. 구버전0.3.5 이하는 새 수정본을 적용하지 못하고 최초 원본만 표시할 수 있습니다. 기존 백업 방식은 유지했으며 이번에 백업 재설계는 하지 않았습니다.
