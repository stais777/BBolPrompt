# 0.4.4 신규 카드 API 판단 보완

[0.4.3용 작은 패치](Bbolprom-API-Quality-Patch-v0.4.3-to-v0.4.4.zip)

1. 진행 중 분석이 끝나면 앱 종료를 누릅니다.
2. ZIP 내용 전체를 현재 Bbolprom.exe 폴더에 덮어씁니다. app만 복사하지 않고 EXE·BUILD_PROVENANCE.json·SHA256.json도 함께 복사합니다. data 폴더는 유지합니다.
3. 0.4.4-quality를 확인합니다. API 설정의 사용자 검수 중점은 선택 사항이며 입력하면 요청에 함께 보냅니다. 모델·키·한도·분류 정의를 자동 변경하지 않습니다.
4. 동일 시험 카드에 각각 한 번씩 분석을 실행합니다. 오늘 기록에 추가 호출 여유가 있어야 합니다. 원문과 수동 태그는 비교 전에 수정하지 않습니다.
5. 새 XLSX를 내보냅니다. 태그검수 시트에서 원래 API 제안·사유·기존 표준·보정 사항을 확인할 수 있습니다. 변경 전 내보내기는 유지합니다.

106개 Python/HTTP 검사와 17개 Chromium 검사를 통과했습니다. 고정309·보안·한도 관련12소스 해시가 같으며 새 API 규칙은 별도 모듈에 있습니다. 실제 모델 품질과 새 Windows 실행은 별도 실측이 필요합니다. 기존 자료 재생 검사는 합성 입출력 검사입니다.

개인 선호 메모·사전/사후 실제 시험 자료·진단 원본은 공개 배포에 포함하지 않습니다. 영상 그룹 DB와 영상 탭은 이번 패치에 구현하지 않았습니다.
