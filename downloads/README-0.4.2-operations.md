# 0.4.2 등록·API 응답 수정

[0.4.1용 작은 패치 약191KB](Bbolprom-Operations-Patch-v0.4.1-to-v0.4.2.zip) · [전체 Windows ZIP](Bbolprom-Windows-x64-v0.4.2-operations.zip)

1. 프로그램 안에서 **앱 종료**를 누른다.
2. 패치 ZIP의 내용 전체를 현재 **Bbolprom.exe가 있는 폴더**에 덮어쓴다. **data는 그대로 둔다.**
3. 다시 실행하고 상단 **0.4.2-operations**를 확인한다. 기존 카드·PT·키 재등록은 필요 없다.
4. 문제 카드의 **분석 상태 확인**을 먼저 누른다. 기존 로컬 기록만 읽으므로 추가 모델 호출을 하지 않는다.
5. **진단 로그 내보내기**로 새 ZIP을 만든다. 이전 실제 API 실패의 원인은 이 기록으로 추가 확인한다. 확인 전 분석을 다시 누를 필요는 없다.

등록/분석의 진행·실패를 해당 화면에 표시하고, 분석 대기 중 숨김·수동 수정이 막히던 문제와 중복 분석을 수정했다. ‘카드 숨기기’는 복구 가능한 숨김이며 영구 삭제는 추가하지 않았다.
