# 뽈프롬 Windows 0.3.2-baseline 개발판

[Windows 실행 ZIP 다운로드](Bbolprom-Windows-x64-v0.3.2-baseline.zip)

이전 앱을 종료하고 ZIP 전체를 새 폴더에 풀어 **Bbolprom.exe**를 실행하세요. app/runtime 폴더도 함께 유지합니다. Python 설치는 필요 없습니다. 데이터는 %LOCALAPPDATA%\Bbolprom에 유지됩니다.

- UI인계 v0.8의3영역·4보기·5테마/강조색·선택후AND적용·이미지/태그/원문·숨김·정렬·대표태그·복사/확대/저장·신규수정/이력복원을 반영했습니다.
- 시작은 빈 갤러리입니다. 승인309개 기준자료는 별도로 준비하고, [확정 PT 이미지 연결]에서 원본을 선택→검토→등록하면 표시합니다. 카드 ID를 재분리하지 않습니다.
- 승인기록·태그/하이라이팅 방법을 API가참조합니다. API는 기본꺼짐이며 실제공급자/모델/키/분류정의/전송동의 설정이필요합니다.
- 111개통합시험,합성베이스화화면5개·기존화면16개·UI인수15개통과. Windows x64 교차빌드 및1342파일해시검증/호스트에서패키지소스 시작검사를수행했습니다.
- 실제 Windows 실행·실제 PT 전체이미지 연결·실제 API 의미품질은 미검증입니다. 한컴원스텝DnD·영상연계·새문서갱신비교·반입롤백·세컨드리키·전체bak복원은 후속입니다.
