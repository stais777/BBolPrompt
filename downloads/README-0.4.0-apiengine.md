# 신규 카드 API 엔진 0.4.0

[0.3.8/0.3.9용 공용 업데이트 ZIP](Bbolprom-API-Engine-Patch-v0.3.8-v0.3.9-to-v0.4.0.zip) · [전체 Windows ZIP](Bbolprom-Windows-x64-v0.4.0-apiengine.zip)

작은 업데이트는 약205KB입니다.

1. 현재 앱 안의 **앱 종료**를 누릅니다.
2. ZIP 안의 **app 폴더와 모든 파일**을 현재 **Bbolprom.exe가 있는 폴더**에 복사하고 같은 이름은 바꿉니다.
3. Bbolprom.exe를 다시 실행합니다. 상단0.4.0-apiengine 표시를 확인합니다. PT를 재등록하거나 data를 옮길 필요가 없습니다.

**API · 대분류 설정 → 정의 초안 · 교정 이력 열기**에서 정의를 검토/수정하고 확정합니다. 기존 사용자 확정 정의도 사용할 수 있습니다. API키는 프로그램의 Windows 보관함에 입력하고 모델 접근/현재 단가/일일 한도/전송 동의를 확인하세요. 이번 개발에서는 실제 키나 유료 API를 사용하지 않았습니다.

신규 카드의 **이 카드 API 분석**, **API · 태그 이력**을 제공합니다. 수동 수정/제외 보호, 로컬 한영 참고 검색, 반복 근거 검증, 최신 교정의 제한된 참고/철회, 태그 이력·복원을 별도 모듈에 연결했습니다. 교정 원문 사례 외부 참고는 기본 꺼짐이고 별도 옵션입니다. 개별 교정은 모델 재학습이나 전체 규칙 자동 변경이 아닙니다.

최초309개 원문/태그/하이라이팅·이미지 매핑과 사용자 수동 수정 이력은 보존합니다. 원래 없어 복원할 수 없는 과거 삭제 이력은 재구성하지 않으며, 새 제외/교정 이력은 이 업데이트 이후 저장에서 기록합니다. 실제 비슷한 의미/다른 이름의 판단 정확도는 실API 평가가 필요합니다.

API 태그 작업마다 전체 PT/이미지를 ZIP으로 복제하지 않고 전후 이력을 저장합니다. 최초 API 초기화 전에 생성하는 backup/*.db-snapshot은 DB만 담은 파일이며 전체 원본 백업이 아닙니다. 기존 **백업 저장**은 DB/API기록·원본 미디어/문서를 포함합니다. 전체 백업 가져오기 UI는 아직 없습니다.

통합223개(새35개 포함), API표적30개, 새 API 화면8개·베이스 수동 화면9개·기존 화면16개 통과. 베이스/보관/보안/API공용20파일SHA불변.0.3.8과0.3.9 각각에 패치를 적용한1359파일이 전체번들과 같고, 임시 기존DB/기준309/수동태그/이미지/일일 원장이 유지되며 새 모의API가 동작함을 Linux에서 검증했습니다.

**미검증:** 새0.4.0의 실제 Windows 실행, 실제 계정/모델 호환, 실제 신규 카드 추천 품질·비용·지연, 실제605MB PT를 개발환경에서 실행. Hancom 이미지 드래그앤드롭은 별도 기억 요구사항으로 이번에 구현하지 않았습니다. 모의 응답을 실제 품질 합격으로 보고하지 않습니다.
