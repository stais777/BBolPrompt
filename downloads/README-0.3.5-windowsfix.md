# Windows 0.3.5-windowsfix · 등록 저장 오류 수정

[EXE 포함 ZIP 다운로드](Bbolprom-Windows-x64-v0.3.5-windowsfix.zip)

사용자0.3.3 진단에서는 원본 베이스파일 검사와522개 이미지 검토가 완료됐으나 등록 중 접근 거부가 발생했고 저장 연결은0/531건이었습니다. 열린 임시 백업 DB를 닫기 전에 삭제하는 결함을 Windows 파일 잠금 모형으로 재현하고 수정했습니다. 검토창 내부에 진행·실패 안내도 표시합니다.

1. 이전 프로그램에서 **앱 종료**를 누르세요.
2. 이 ZIP 전체를 새 폴더에 풀고 **Bbolprom.exe**를 실행하세요. EXE·app·runtime 폴더를 함께 유지합니다. Python 별도 설치는 필요 없습니다. 기존 데이터 폴더를 그대로 사용합니다.
3. 베이스파일 PT.hwpx 선택 → 검토 → **검토한 이미지 연결 등록**을 진행하세요. API 키는 필요 없습니다.
4. 성공하거나 오류가 나면 **진단 로그 내보내기**로 저장한 Bbolprom-Local-*.diagnostic.zip을 전달해 재확인하세요.

고정309개 카드·531개 순서 참조·522개 원본 경로·태그/하이라이팅 판단 방식은 유지했습니다. API 보안 준비 기능을 포함하며 후속 엔진 개선은 보류 중입니다.

통합140개, 그 안의 새 Windows 잠금 모형3개, 로컬 브라우저6개를 통과했습니다. 수정 전 잠금 시험은3개 모두 실패했고 수정 후 통과했습니다. 브라우저는 저장 실패 주입 → 진단 → 같은 세션 재시도 →531개 연결/522경로 저장 해시를 확인했습니다. Windows 교차 빌드·1347개 파일 해시·ZIP CRC·Linux 호스트의 패키지 소스/백업 시험을 통과했습니다.

**실제 Windows의 수정 후 등록 성공은 아직 확인하지 않았습니다.** 제공된 이전 Windows 진단에서 확인한 원본 읽기 성공과 구분합니다. 실제 API 호출·키·원본605MB 파일의 개발 환경 실행은 없었습니다. 원본 사용자 진단은 이 배포본에 넣지 않았습니다. 자세한 내용은 [등록 오류 수정 기록](../docs/WINDOWS_REGISTRATION_FIX.md)을 참고하세요.
