# 고정 309카드 베이스화 등록 경로

소스 개발판:0.3.2-baseline-dev. 기존 배포 Windows 0.3.1 ZIP에는 아직 포함되지 않았다.

사용자가 정한 베이스화는 **검증된 마스터의 309개를 데이터로 등록하는 것**이다. 이번 구현은 이 경로이며 독립 파서의 성공이나 495→309 분리 개선을 의미하지 않는다.

## 저장과 등록

`baseline.py`는 기존 `assets/approved_catalog.json`과 이번에 받은 베이스 검수의 `04_카드별_원문_이미지_매니페스트.json`을 SHA256으로 고정하고 원문·이미지 순서를 교차 확인한다. 후자는 바이트 변경 없이 `bbolprom_engine/data/baseline_manifest.json`에 보존했다.

앱 시작 시 SQLite의 `baseline_cards`에 001~309를 각각 등록한다. 일반 신규 카드의 원문SHA 중복 제거와 별개다. 동일원문12그룹도 합치지 않으며8471태그·10358근거·승인된 빈근거17건은 그대로다. `baseline_image_links`에는531개 참조를 먼저 등록하고 실제 이미지가 없으면 미연결 상태로 둔다.188번은0개,109번은image195 하나,110번은image196~209의14개다.

카드 레코드와 이미지 참조의 ID/순서/경로는 DB트리거로 변경·삭제를 막는다. 원본 마스터/카탈로그/방법론 자료에 쓰지 않는다. 신규 운영 카드는 기존 `cards`에 따로 저장한다. 현재 사용자 태그의 확정/제외 상태를 재분석에서 완전히 보호하는 계약은 후속 작업이다.

## 확정 PT의 이미지 연결

기존 반입 버튼과 끌어놓기는 `POST /api/baseline-upload`로 연결한다. 파일SHA가 확정 PT의 `c5d52ce0cda5901d9da178f88c8d5c2eeb5614eefa5a0546916e4951df881ddf`와 같아야 한다. 이름이 PT.hwpx라는 이유만으로309개로 처리하지 않는다. 다른/갱신된 문서는 거절하고 기존 데이터를 유지한다.

확정 매니페스트의522개 경로만 읽어 MD5/SHA1/SHA256을 계산하고309개 고정 카드의531참조로 검토창을 만든다. XML본문 파싱·로컬 경계 추론·태그 추론을 실행하지 않는다. 검토창의 ID/원문/참조는 편집 대상이 아니다. 등록은 `POST /api/baseline-commit {ticket}`만 받으며, 검토 후 전체파일SHA와 이미지 해시를 다시 확인한다.

등록 전 `.bak.zip`을 만들고 이미지 원본 바이트를 저장한 뒤531개 링크를 한 DB트랜잭션으로 연결한다. 실패 시 DB링크는 전부 롤백한다. 파일 저장소에는 실패 중 만들어진 미연결 해시객체가 남을 수 있으며 기존 카드를 가리키는 링크나 이미지 바이트는 바꾸지 않는다. 같은 파일 재등록은 카드/링크/소스 레코드를 추가하지 않는다.9개 공유 경로는 같은 미디어 객체를 참조한다.522는 서로 다른 원본 경로 수이며 서로 다른 픽셀/콘텐츠 수를 단정한 값이 아니다.

기존 `/api/upload`와 편집 검토는 진단 회귀 호환을 위해 남겼다. 현재 제품 반입 버튼에서는 사용하지 않는다. 신규 프롬프트+이미지 등록 및 API 분석 경로는 유지한다. 소스 새 버전 비교·충돌 검토·누락 카드의 버전별 상태·반입 단위 롤백은 아직 미구현이다.

## 검증 범위

- 통합시험105/105:고정ID/중복 보존·109/110·188·531참조·공유 이미지·재시작·재등록·잘못된파일/변경파일/해시불일치 롤백·실제localhost HTTP·백업/내보내기.
- 베이스화 Chromium 시험5개:잘못된파일 거절,309개 검토,취소,등록/재등록,새로고침 보존. 합성522자산을 사용하며 테스트 전용 프로세스에서만 합성파일SHA를 대체한다. 제품에는 이를 허용하는 설정이 없다.
- 기존 화면 회귀16개:갤러리/검색/형광펜/신규카드/태그편집/백업/내보내기 및 기존 진단 경로. 제품 신규 반입과 진단 회귀를 구분한다.
- BMP/JPG 참조를 확인하고 BMP 바이트의 응답MIME와 브라우저 표시를 검증했다. 실제 PT이미지 바이트로 시험한 것은 아니다.

증빙:`evaluation/baseline-integrated-tests.log`, `baseline-browser-smoke.json`, `browser-smoke.json`. 실제 PT원본·522이미지는 미제공이며 실제API 의미품질·Windows 네이티브 실행은 미검증이다. 이번 기능을 실제 원본 전체 실행 성공이라고 보고하지 않는다.
