## 직접 확인한 상호 일치

- 체크섬 목록의13개 파일을 SHA로 검증했다. ZIP 원본 SHA는 `afe4b54fed0c08e704aad28dc2f984dd6b049e578afd7e8c5e741210438635ae`다.
- 카드ID001~309, 원문309개, 각 원문UTF-8 SHA, J열 이미지 참조의 순서가 매니페스트·마스터·기존 카탈로그와 일치한다.
- 모든 카드의 원문 문단 범위·분석 회차·마스터 행 번호와 CSV의 이미지 연결/경로 순서를 대조했다.
- 카드 이미지 참조531행이 과거 최종검수JSON의 `card/ref/path`531행과 순서까지 같다. 이 보고서의 서로 다른 경로는522개다.
- 이미지 없는 카드188, 다중 이미지 카드70, 공유 경로9개를 보존한다.

- 보조 검수이력JSON19시트는 마스터와 내용이 같다. 검수이력의 빈 셀(`null`/빈문자열) 및 끝쪽 빈 열 패딩 표현 차이만 비교 시 허용했다. 카드 원문이나 태그 문자열은 정규화·변경하지 않았다.

## 현재 개발에 적용할 기준

베이스화 자료의 카드ID를 태그마스터/누적하이라이팅JSON의 같은 카드ID에 연결한다. **원문 해시만으로 기존309개 카드를 통합하지 않는다.** 이 자료로 HWPX를 다시495개 후보로 분리할 이유가 없다. 과거 검증기의 승인 원문 검색은 베이스 대조이지 새로운 독립 분리 엔진의 성공 증거가 아니다.

현재 우선 작업인 승인 기록 대조/API방법 연결은 이 고정ID 관계를 기준으로 한다. 실제 베이스화 등록·이미지 가져오기 경로의 제품 변경은 이번 자료 대조와 구분한다. 기존 프로그램에 사진까지 새로 등록했다고 보고하지 않는다.
