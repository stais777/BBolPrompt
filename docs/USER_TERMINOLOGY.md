# 사용자 확정 용어와 처리 순서

## 베이스화

사용자 정의: **확정된 309카드를 고정 데이터로 제공받아 그대로 등록하는 작업을 ‘베이스화’라고 한다.**

- 등록 기준은 인계받은 확정 마스터 엑셀이다.
- 승인된 원문·태그·분류·근거 등의 데이터를 그대로 보존한다.
- 베이스화는 엔진이 독립적으로 카드나 태그를 생성했다는 뜻이 아니다.
- 화면에 베이스화된 309카드가 존재하는 것은 독립 엔진 시험의 성공 근거가 아니다.

## 사용자가 확인한 순서

1. 승인 309카드의 정답을 참조하지 않은 상태에서 엔진으로 카드 추출·태그 선정·분류를 먼저 시험한다.
2. 그 결과로 기존 승인 수준의 처리가 불가능하면 확정 마스터 엑셀의 309카드를 정확히 베이스화한다.

## 이후 사용자께서 확정한 방향

- 로컬 규칙으로 PT를 다시 분할하는 시도는 중단한다. 마스터 엑셀에서001~309카드가 정확히 구분된 사실은 이미 검증됐다.
- 베이스화된 승인 사례와 인계된 태그 선정·분류·정규화·하이라이팅 작업 방법을 API가 신규 등록에 활용하도록 한다.
- AI와 사용자 간 정반합으로 남긴 승인·교정·통합·삭제·유지 기록을 사용한다. 기록이 없는 판단 사유는 만들지 않는다.
- 현재 우선 작업은 최종 승인과 후속 수정·철회를 구분하고, 출처를 보존해 API에 연결하는 일이다.
- UI인계는 처음에 보관만 요청했으나2026-11-05 “ui도 보고 반영해주세용”으로 분석·적용을 승인했다. v0.8 배치/4보기/5테마/선택후AND적용 등을 구현한다. 별도 태그/하이라이팅 방법론 인계도 참조한다.

이 문서는 사용자가 실제로 확정한 내용만 기록하며 이후의 제품 정책을 임의로 덧붙이지 않는다.

## 추가 자료의 역할
