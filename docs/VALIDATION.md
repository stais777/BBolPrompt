## 실측 A/B와 이번 회귀의 관계

실제 A(generic)/B(approved_terms) 실패 수치는 `docs/ANALYSIS.md`, 카드별 내역은 `evaluation/historical-card-failures.csv`에 있습니다. 실제 원본 SHA는 동일하지만 이번에 PT 원본을 제공받지 않았으므로 **실제 A/B 재시험이나 실제 개선율 측정은 하지 않았습니다.** 합성 회귀의 개선은 확인된 코드 결함에 대한 근거이며 실제 PT 품질 추정이 아닙니다.

패키지의 simulated HWPX는 309개 단문단과 이미지 참조0개라 531개 참조 귀속의 시험 자료로 사용할 수 없습니다. 승인 갤러리의 원문이 같다는 이유로 신규 HWPX 카드 경계를 강제 맞추지 않습니다.

## 미실행·미완성

- 실제 PT의 309/531 재추출 및 개별 이미지 귀속, 실측 태그/근거 개선율: **미실행**. 605MB 실제 PT 원본 필요.
- 실제 AI API 호출·새 프롬프트 의미 정확도·실제 비용: **미실행**. 키·공급자·모델·전송 동의·사용자 분류 정의 필요. 24개 API 관련 자동시험은 모의 공급자/응답 계약 시험이지 의미 품질 시험이 아님.
- Windows 네이티브 OS 실행/설치/이미지 표시/긴 경로/사용자 PC 호환성: **미실행**. Windows 배포 내 `test_windows.ps1`은 재현 가능한 시험 도구이며 여기에서 실행하지 않았음. Linux 호스트에서 번들 소스 smoke를 실행한 것은 Windows 실행이 아님.
- 모호한 HWPX의 모든 배치에 대한 자동 경계 보장: **불가**. 검토 경고 및 사용자 경계/귀속 수정 제공.
- 반복 근거의 의미별 문맥 선택: 모든 실제 일치 구간과 모호성 경고를 제공하나 API 응답에 문맥 선택기를 완전히 연동하지 않았음.
- 다중 카드 태그 일괄 편집·OS 키체인 직접 연동·업데이트·코드서명·설치 마법사: **미구현**.

기존 승인 309 원문은 296개 고유 원문 해시입니다. 같은 원문이라고 승인 카드를 자동 합치지 않으며, 복수 승인 카드 중 이미지·출처의 대상은 명시적으로 선택합니다. 결과물은 검증 범위를 명시한 개발판이며 정식 완성/Windows 실행 완료로 표현하지 않습니다.

## 0.3.1과 사용자 실제 실패의 구분

사용자 PC에서 실제 PT 반입 검토495개, 기존 갤러리309개가 확인됐습니다. 495개 추출은 실패 사례이며 수정 완료가 아닙니다. 원본 XML을 확보할 수 있도록 구조 진단 ZIP 저장을 추가했고, 관련 승인 카드 원문·태그·근거의 명시적 API 사례 참조를 구현했습니다. 신규 API 사례 테스트와 HTTP 연결은 모의 공급자 검증이며, 위80개 자동시험·16개 Chromium 시나리오는 실제 PT 개선율이나 실제 API 의미 정확도를 나타내지 않습니다. 자세한 변경은 `0.3.1-diagnostic.md`를 참고하세요.
