# 로컬 PT 반입 결과 내보내기

0.3.3-baseline 개발판에 추가했다. 사용자PC의600MB원본을 직접 받지 않고도 베이스화·이미지 연결·저장상태를 점검하기 위한 진단이다.

1. ZIP전체를 새 폴더에 풀고Bbolprom.exe를 실행한다.
2. 확정 PT.hwpx 선택→반입 검토→등록을 실행한다. 파일/등록 오류가 나도 다음 단계로 진단할 수 있다.
3. 좌측 **진단 로그 내보내기**를 누른다. 검토창에도 버튼이 있다.
4. 다운로드한 `Bbolprom-Local-*.diagnostic.zip`을 채팅에 첨부한다.

## 기록하는 내용

- 프로그램버전·빌드소스커밋·실행OS/아키텍처/Python버전.
- 반입 시작/원본SHA계산/검토준비/등록/실패/취소 이력과파일명·크기·전체SHA256. 최근20개를내보내고전체개수와생략여부를명시한다.
- 고정309개ID,296개고유원문해시,8471태그·10358근거·승인된빈근거17건의무결성. 원문/태그문자열대신해시·개수·좌표오류위치를기록한다.
-531참조/522경로의카드별순서,원본에서실측한MD5/SHA1/SHA256과저장파일을다시읽은해시/크기 비교. 공유이미지를중복해서읽지않는다.
- SQLite quick_check/외래키,원본대조가능여부,화면의표시카드/이미지로드수·필터상태개수.

내보내기중저장파일을다시읽으므로이미지양과PC속도에따라시간이걸릴수있다. 이작업은검사/새진단파일생성만하며카드·원본파일을수정하지않는다.

## 포함하지 않는 내용

ZIP에는 `report.json`, `SUMMARY.txt`만들어간다. 실제원문·이미지바이트·문서XML·SQLiteDB·API키/설정·환경변수·원본절대경로는포함하지않는다. 파일명·이미지참조·카드ID와해시는포함된다. 자동외부전송은없다.

## 상태 해석

- `not_imported`:아직정식등록이없음. 마지막시도가검토준비/실패/취소인지별도로확인한다.
- `passed_integrity`:고정기준·등록된소스SHA·이미지연결·원본에서측정한해시와저장파일재검증이일치함.
- `failed_integrity`:연결개수와별개로파일없음/변조/원본-저장불일치/DB/고정자료/근거구간오류가있음.
- `passed_storage_integrity_source_comparison_unavailable`:이전버전반입등으로원본실측해시기록이없음. 현재저장무결성만확인됨. 새버전에서PT를다시선택·검토·등록하면원본대조기록을남길수있다.

이로그는고정마스터베이스화검사다. 로컬독립분리성능·사진/프롬프트의의미상일치·실제API태그품질·모든Windows조작합격을증명하지않는다. 실제사용자로그가오면실행OS와각실측결과를그범위로검토한다.

시험:추가9개계약/실제localhost HTTP시험과실제버튼5개브라우저시험. 성공뿐아니라다른SHA,검토취소,검토후원본변경,저장파일삭제/변조,이전버전기록부족도검증했다. 통합120개통과. 합성자료이며실제PT/Windows/외부API시험은아니다.
