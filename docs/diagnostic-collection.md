# HWPX 구조만 수집하는 오프라인 도구

실제 PT 반입 검토창에서 495개로 나뉜 원인을 조사하기 위한 도구입니다. 카드 수를 309로 맞추는 프로그램이 아닙니다. **원문·이미지의 실제 XML 배치를 보고 경계 결함을 재현**하는 데 사용합니다.

## 수집 방법

1. `collect_hwpx_structure.cmd`와 `collect_hwpx_structure.ps1`을 같은 폴더에 둡니다.
2. 사용 중인 `PT.hwpx`의 복사본을 `collect_hwpx_structure.cmd` 위로 끌어 놓습니다.
3. Windows 기본 PowerShell/.NET만 사용합니다. Python을 설치할 필요가 없습니다.
4. 바탕 화면에 `Bbolprom-structure-날짜-고유값.zip`이 생성됩니다. 이 ZIP을 채팅에 첨부하면 됩니다. 출력 파일은 원본 이름을 따라 긴 경로를 만들지 않습니다.

PowerShell 실행 정책이나 회사 보안 정책이 차단하는 경우 정책을 우회하지 말고 오류 메시지를 보존하세요. 프로그램에 제공된 진단 내보내기 경로를 사용하거나 다른 전달 방법을 확인하면 됩니다.

## 들어가는 자료와 제외되는 자료

- `Contents/*.xml`, `Contents/content.hpf`, `META-INF/*.xml`, `version.xml`, `mimetype`을 원본 바이트 그대로 복사합니다. 하위 경로의 XML도 포함합니다.
- `_diagnostics/structure-report.json`에는 원본 파일명·크기·SHA256, ZIP 멤버 이름/크기, 복사한 XML별 SHA256, 섹션별 문단/표 행/이미지 참조/명시적 페이지 나눔 개수가 들어갑니다.
- `BinData`와 미리보기 이미지 등 실제 이미지 파일 엔트리는 복사하지 않습니다. 605MB HWPX를 통째로 올리지 않고 구조만 전달하기 위한 목적입니다.
- **XML 안의 프롬프트 원문은 포함됩니다.** 원문을 삭제하면 문제의 문단 배치/카드 경계를 재현할 수 없습니다. 원본 XML 자체에 별도 인라인 데이터가 들어 있으면 그것도 원본 그대로 남습니다.
- API 호출, 네트워크 업로드, 기존 앱 DB 읽기/수정, 카드 등록, 승인 309카드 수정은 하지 않습니다. 출력 ZIP을 첨부하는 동작은 사용자가 직접 합니다.

## 보호 및 검증 한계

원본을 읽기 전용 파일 핸들로 열고 원본과 별개인 새 ZIP에 기록합니다. 동일한 이름의 기존 출력 파일을 덮어쓰지 않습니다. 파일 전체 SHA256을 읽는 시간은 PC와 원본 크기에 따라 달라질 수 있습니다.

원본 이미지 파일 바이트가 빠지므로 이 진단 ZIP으로 원본 이미지 픽셀·MD5/SHA1을 재검증할 수는 없습니다. XML에 남은 이미지 참조 ID와 원문·배치 정보로 카드 분리를 재현할 수 있습니다. 진단 ZIP을 원래 PT.hwpx 대신 재등록하면 안 됩니다.

**검증 상태:** Linux 개발 환경에서 소스 정적 검토만 수행했습니다. Windows PowerShell에서 이 수집기를 실행한 시험은 아직 수행하지 않았습니다. 수집 성공이나 Windows 호환성을 미리 완료로 보고하지 않습니다.
