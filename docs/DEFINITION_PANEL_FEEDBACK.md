# 정의 초안 설정창의 진행·오류 표시 보완

0.4.1-apifeedback, 2026-11-06 한국시간.

사용자가 0.4에서 정의 초안·교정 이력 열기를 눌러도 반응이 없다고 보고했다. 기존 코드는 실패 시 갤러리의 상태줄에만 오류를 표시해 열린 설정창에 가려졌다. 합성 실패 응답으로 실제 Chromium에서 이를 재현했다. 설정창은 열린 상태이고 내부 상태는 빈 문자열, 바깥 상태줄에는 오류가 있었다.

## 변경

- 클릭 즉시 설정창 안에서 처리 중임을 표시하고 패널 버튼·입력의 중복 조작을 막는다.
- 열기·확정 실패는 설정창 안에서 알리고 재시도를 허용한다. 성공 문구는 기존 정의 확정 개수 표시를 유지한다.
- 응답과 표시할 내용이 모두 준비된 뒤 교체한다. 실패 시 기존 정의와 저장 전 편집값을 보존한다.
- 오류는 textContent와 길이 제한·키 형식 마스킹으로 표시한다.

베이스화·태그 판정·근거 계산·키 보관·모델 통신·과금 원장은 변경하지 않았다. 설정창 열기·정의 확정으로 실제 모델을 호출하지 않는다.

## 검증과 한계

`scripts/api_engine_feedback_browser_smoke.js`의 새6개 검사와 기존 API 화면8개가 통과했다. 새 검사는 모의 엔진을 미리 초기화하지 않는 서버에서 정의 불러오기 실패·재시도, 실제 로컬 초기화, 사용자 편집값 보존, 확정 실패·재시도,309개 기준/키/호출0회를 확인한다. 수정 전 JavaScript에서는 설정창 안 오류 확인이 실패함을 기록했다.

이것은 오류 표시 결함의 수정이다. 사용자PC에서 정의 불러오기가 실패한 실제 원인은 아직 오류 문구를 받아야 확정할 수 있다. Windows에서 이 보완 버전을 실행하거나 실제 API를 호출하지 않았다. 기존0.4 사용자진단의 Windows 실행·PT원본보관/309무결성 통과와 구분한다.
