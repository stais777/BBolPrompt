반입 전 검토
아래 번호는 이번 파일에서 추출한 검토 카드 번호입니다. 갤러리의 기존 승인 카드 번호와 다릅니다. 추출 경계의 정확성은 아직 확인되지 않았습니다. 경계가 모호하면 인접 카드를 병합하거나 문단 단위로 분리하세요. 원본 파일은 변경되지 않으며 검토 편집은 신규 반입 결과에만 적용됩니다.
원문·XML·분석 보고서를 이미지 없이 로컬 파일로 저장합니다. 외부로 전송하지 않습니다.


베이스화 이미지 연결 검토
확정 마스터의 309개 카드 ID·원문·태그·하이라이팅을 유지합니다. 원본을 다시 분리하거나 태그를 재분석한 결과가 아닙니다. 같은 원문을 가진 카드도 각각 보존합니다.
원문·이미지 없이 파일SHA와 카드별 연결·저장 무결성을 기록합니다.


카드 태그 직접 수정
태그명 · 활성 대분류 · 정확한 원문 근거를 입력합니다. 근거가 없는 태그도 0구간으로 보존합니다. 이미 있던 다중 구간은 기존 근거들을 유지합니다.


API · 사용자 대분류 설정
외부 전송: 선택한 신규 카드 원문, 활성 분류 정의, 관련 표준 태그와 승인 이력 일부. 아래 사례 참조를 선택하면 관련 승인 카드의 원문 발췌·태그·근거도 최대 3건 제공합니다. 승인 309 전체 원문이나 이미지 바이트는 API에 보내지 않습니다. 실패 시 카드는 보존되며 자동 재호출하지 않습니다.
키는 Windows 보안 보관함에만 저장하며 설정·백업·진단 파일에 포함하지 않습니다. 기존 환경변수의 키는 읽지 않습니다.
호출 기록은 재실행·설정 변경 후에도 유지됩니다. 실패한 호출도 횟수와 비용 예약에 포함되며 자동 재시도하지 않습니다. 실제 청구는 입력한 단가와 공급자 정책에 따라 다르므로 계정의 결제 제한도 별도로 설정하세요.
대분류
초기 표시명만 제공됩니다. 명확한 사용자 확정 정의를 저장한 활성 분류만 API에 보냅니다. 정의 변경은 신규 분석부터 적용됩니다. 비활성화는 소속 태그를 미분류로 표시하며 원본·근거는 보존합니다.
