뽈프롬 PromptManager · 0.3 개발판

검증 상태 · 원본 보호

승인 309 원문·태그·근거는 읽기 전용입니다. 이미지는 원본 패키지에 없어 참조만 표시합니다. API는 기본 꺼져 있으며 규칙 태그를 의미 분석 결과로 등록하지 않습니다.

카드를 선택하세요. HWPX를 이 창으로 끌어 놓아 반입할 수도 있습니다.

출처 · 해시



프롬프트 + 이미지 직접 등록
원문을 그대로 보존합니다. 같은 원문이면 카드에 이미지를 추가하고 파일별 출처를 보존합니다.


반입 전 검토
경계가 모호하면 인접 카드를 병합하거나 문단 단위로 분리하세요. 원본 파일은 변경되지 않으며 검토 편집은 신규 반입 결과에만 적용됩니다.


신규 카드 태그 직접 수정
태그명 · 활성 대분류 · 정확한 원문 근거를 입력합니다. 근거가 없는 태그도 0구간으로 보존합니다. 이미 있던 다중 구간은 기존 근거들을 유지합니다.


API · 사용자 대분류 설정
외부 전송: 선택한 신규 카드 원문, 활성 분류 정의, 관련 표준 태그와 승인 이력 일부. 승인 309 전체 원문이나 이미지 바이트는 API에 보내지 않습니다. 실패 시 카드는 보존되며 자동 재호출하지 않습니다.
대분류
초기 표시명만 제공됩니다. 명확한 사용자 확정 정의를 저장한 활성 분류만 API에 보냅니다. 정의 변경은 신규 분석부터 적용됩니다. 비활성화는 소속 태그를 미분류로 표시하며 원본·근거는 보존합니다.
