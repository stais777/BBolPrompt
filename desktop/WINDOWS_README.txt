뽈프롬 PromptManager 0.3 개발 빌드 (Windows 10/11 x64)

1. ZIP 전체를 짧은 경로(예: C:\Bbolprom)에 압축 해제합니다.
2. Bbolprom.exe를 실행합니다. Python을 별도로 설치할 필요가 없습니다.
3. 기본 브라우저에 로컬 프로그램 화면이 열립니다. 데이터는 PC에 저장합니다.
4. app 및 runtime 폴더는 실행 파일과 함께 두어야 합니다.

이 배포본은 Linux에서 Windows x64로 크로스 빌드한 개발 버전입니다.
Windows PC에서 직접 실행한 검증 결과는 아직 없습니다.
실제 605 MB PT.hwpx 파일 및 API 키는 포함되어 있지 않습니다.
실제 PT 재시험과 실제 외부 API 의미 품질 평가는 별도로 필요합니다.
디지털 서명이 없는 개발 빌드로, Windows에서 게시자 확인 창이 표시될 수 있습니다.
BUILD_PROVENANCE.json과 SHA256.json에서 빌드 출처/파일 무결성을 확인할 수 있습니다.

확정 XLSX 원본과 평가용 정답 파일은 포함하지 않았습니다.
309개 승인 카드는 원본을 덮어쓰지 않는 읽기 전용 갤러리 카탈로그로 표시합니다.
이 갤러리 카탈로그는 신규 카드의 운영 추론/강제 경계 맞춤에 사용하지 않습니다.
API 키를 프로그램 폴더, 압축파일, Git 또는 보고서에 저장하지 마십시오.
