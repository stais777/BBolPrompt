뽈프롬 PromptManager 0.3.3-baseline 개발판 (Windows 10/11 x64)

1. 이전 프로그램을 종료하고 ZIP 전체를 새 폴더(예: C:\Bbolprom-0.3.2)에 압축 해제합니다.
2. Bbolprom.exe를 실행합니다. Python을 별도로 설치할 필요가 없습니다.
3. app 및 runtime 폴더는 EXE와 함께 유지하세요. ZIP 안에서 EXE만 꺼내 실행하면 안 됩니다.
4. 기본 브라우저에 프로그램이 열리고 데이터는 %LOCALAPPDATA%\Bbolprom에 저장됩니다.

베이스화
- 시작할 때 확정 마스터의 309개 카드 ID·원문·태그·하이라이팅을 고정 데이터로 등록합니다.
- 같은 원문을 가진 역사적 카드도 각각 유지합니다. 독립 카드 분리 성공을 뜻하지 않습니다.
- [확정 PT 이미지 연결]에서 원본 PT.hwpx를 선택하고 검토한 후 등록하세요.
- 확정 원본의 전체 SHA256을 확인하고 522개 경로의 이미지를 531개 카드 참조에 연결합니다.
- 188번은 이미지가 없는 정상 카드이며 109번은1개,110번은14개 참조를 유지합니다.
- 원본과 다른/갱신된 문서는 기존 데이터를 유지하고 거절합니다. 새 버전 비교는 추후 기능입니다.
- 신규 프롬프트+이미지는 [직접 등록]을 사용하세요.

API
- 승인 기록과 태그/하이라이팅 방법을 출처와 함께 참고합니다.
- 기본은 꺼져 있습니다. 공급자·모델·활성 분류 정의·외부 전송 동의를 설정해야 합니다.
- 관련309카드 원문 사례 참조는 별도 선택 옵션입니다.
- 키 값은 채팅·소스·ZIP에 넣지 마세요. 지정한 Windows 환경변수로 제공합니다.
- 실제 API 의미 품질과 비용을 이 빌드에서 실측한 것은 아닙니다.

검증 범위
- Linux에서 Windows PE32+ x64로 교차 빌드했습니다.
- Windows PC 직접 실행 검증과 실제605MB PT 이미지 연결은 아직 수행하지 않았습니다.
- 120개 통합시험, 합성 자료의 베이스화 화면5개·기존 화면16개·UI인수15개를 통과한 소스입니다.
- 2026-11-05 사용자 요청으로 UI인계를 분석하고 v0.8 배치·4보기·5테마·필터·수정복원을 적용했습니다.
- 한컴 원스텝DnD·영상연계·세컨드리키·소스갱신비교·반입단위되돌리기는 후속 작업입니다.

BUILD_PROVENANCE.json에 소스 커밋과 빌드 출처, SHA256.json에 파일 해시를 기록했습니다.
Windows용 test_windows.ps1은 파일 무결성·번들Python·고정베이스·EXE시작을 검사합니다.
이 검사 스크립트를 개발 환경에서 Windows로 실행한 결과는 아직 없습니다.
실제 PT.hwpx·확정 원본XLSX·사용자DB·비밀키·보관 전용UI ZIP은 포함하지 않았습니다.

로컬 진단 로그 (0.3.3 추가)
- [진단 로그 내보내기]는 좌측 라이브러리와 반입 검토창에 있습니다.
- PT.hwpx를 선택→검토→등록한 후 누르면 저장 이미지를 다시 읽어 해시/연결을 확인합니다.
- 잘못된 파일 또는 등록 오류가 나도 좌측 버튼으로 진단 ZIP을 저장할 수 있습니다.
- 다운로드한 Bbolprom-Local-*.diagnostic.zip을 채팅에 첨부하면 카드/이미지/오류를 검토할 수 있습니다.
- ZIP에는 원문·이미지·문서XML·DB·API키가 없습니다. 자동 업로드하지 않습니다.
- 이전0.3.2로 이미 반입한 경우 저장무결성은 검사할 수 있습니다. 원본과의 새 해시대조 기록까지 남기려면 새 버전에서 확정 PT를 다시 선택·검토·등록하세요. 고정ID는 유지합니다.
- 원본과 저장 파일의 해시 일치는 사진 내용의 의미상 적합성을 전수 시각검수했다는 뜻은 아닙니다.
